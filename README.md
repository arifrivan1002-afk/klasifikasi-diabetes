Repositori ini berisi proyek praktikum Machine Learning yang menggunakan dataset Healthcare Diabetes untuk memprediksi status diabetes berdasarkan fitur seperti jumlah kehamilan, kadar glukosa, tekanan darah, BMI, insulin, dan usia. Tahapan proyek meliputi pemuatan dan pembersihan data, eksplorasi data, pemisahan data latih dan data uji, pembangunan beberapa model klasifikasi, serta evaluasi hasil menggunakan metrik seperti accuracy, precision, recall, F1-score, dan ROC-AUC. Proyek ini dibuat untuk keperluan pembelajaran dan bukan untuk diagnosis medis.
